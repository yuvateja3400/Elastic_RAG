Where the ELSER tokens come from (important)

You created an ingest pipeline on the server (one-time cURL) and set it as the index’s index.default_pipeline:

Pipeline: elser_v2_pipeline

Definition: runs the .elser_model_2 text_expansion inference and writes results to ml.tokens:

{
  "description": "ELSER v2: write rank_features to ml.tokens from text",
  "processors": [
    {
      "inference": {
        "model_id": ".elser_model_2",
        "inference_config": { "text_expansion": { "results_field": "tokens" } },
        "field_map":   { "text": "text" },  // read doc's 'text'
        "target_field":"ml"                 // write to 'ml.tokens'
      }
    }
  ]
}
